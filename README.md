# presentacion-acabados
Acabados casa MARILU

## Solicitudes de Cambio

Cuando un usuario pulsa **"Solicitar cambio"** en cualquiera de los espacios,
se abre un formulario para registrar la solicitud. Al enviar se guarda en
`localStorage` junto con la fecha y la página desde la cual se originó.

Para revisar todas las solicitudes, ve a la ruta `/summary` o utiliza el
enlace **Resumen** en la barra de navegación. Allí se listan en una tabla con
la página, la descripción y la fecha de cada solicitud.

Los datos se almacenan localmente en el navegador del usuario, por lo que esta
herramienta es principalmente para pruebas o revisiones rápidas.
